# Task 8 — Bottom Navigation Bar

Multi-page app with BottomNavigationBar for page navigation.

## Features
- 4 navigation tabs (Home, Favorites, Settings, Profile)
- Each tab displays different content
- Uses `setState()` to update the current index
- Clean Material Design with icons and colors

## Run

```bash
cd /workspaces/madlab-pracs/task_8
flutter pub get
flutter run -d web-server
```
