# Task 6 — ListView with Items

Display a scrollable list of items using `ListView.builder` and `ListTile` widgets.

## Features
- 10 items displayed in a ListView
- Each item is a ListTile with title, subtitle, and leading/trailing icons
- Tap any item to see a snackbar confirmation

## Run

```bash
cd /workspaces/madlab-pracs/task_6
flutter pub get
flutter run -d web-server
```
