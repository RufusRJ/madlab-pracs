# Task 7 — Read and Display JSON Data

Display a list of items parsed from a local JSON string using `json.decode()`.

## Features
- Parses a JSON array string into a Dart list
- Displays 8 fruits from the JSON data
- Each item shown in a Card with ListTile
- Uses leading number and trailing icon for visual appeal

## Run

```bash
cd /workspaces/madlab-pracs/task_7
flutter pub get
flutter run -d web-server
```
